# Git Auto-Commit Rule

Whenever you make any modifications to code or project files, you MUST automatically run the following commands to commit the changes to Git at the end of your task, unless the user specifically asks you not to:

1. `git add .`
2. `git commit -m "Auto-commit: <brief description of changes>"`

Do not wait for permission to commit your changes. Make sure to only commit once you have verified that the edits were successful.
