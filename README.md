HMdll (Pronounced as Heim-dall)

HMdll is a study abroad platform that I developed that helps users research about universities, programs, and countries that they are
targeting. The application has scholarship, immigration, cost calculator and career sections as well. The Immigration section contains
information about student visa requirements, employment and permanent residency(PR) permits along with live news and updates about
immigration regarding different countries so that users can stay informed. Users can login to the application and add their profile
details in the dashboard section. I have added a budget and profile analyzer to each university which displays wether the user 
is eligible to apply to the particular university or not. The Career section displays the possible careers that users can 
pursue along with the educational qualification and skills they need to pursue them. I have also added a chat section so that users can
talk to each other regarding university research, visa application and so on. They can also create multiple groups and add other users. 

These are the Languages that I used to develop the application:

  -HTML
  -CSS
  -JavaScript(JSX/Node.js ESM)
  -PostgreSQL

These are the Tools and Frameworks:

  -React.js
  -Framer Motion: Fluid spring transitions, entry animations, interactive modals, and dropdown micro-interactions.
  -Lucide React & React Icons
  -Pusher-js: Real-time WebSocket client for live updates and notifications.
  -@react-oauth/google: Google Sign in authentication components.
  -Node.js
  -Express.js
  -Redis(ioredis)
  -Puppeteer: Headless chromium browser automation used for crawling and scraping university/program data.
  -Google-sr: Search scraping utility for university and program lookup.
  -Pusher Server SDK: Real-time event broadcasting server.
  -Security & Auth Suite
  -JWT (jsonwebtoken)
  -Bcryptjs: Salted password hashing.
  -Google Auth Library: Backend verification of Google OAuth tokens.
  -Helmet: HTTP security response headers.
  -CORS: Cross-Origin Resource Sharing control.
  -Express Rate Limit: Brute-force and DDoS rate limiting.
  -Validation & File Uploads
  -Joi: Object schema validation for API request payloads.
  -Multer: Multipart form-data handling for user document and resume uploads.
  -Nodemailer: SMTP email transport for account confirmations, alerts, and transactional messages.
  -Morgan: HTTP request logger middleware.

These are the DevOps & Infrastructure, APIs & Web Services

  -Internal HMdll REST API: Custom backend endpoints powering authentication, university search/filters, scholarship tracking, career guides, counselor booking, and application management.
  -Google Identity / OAuth 2.0 API: Third-party single sign-on authentication.
  -Pusher Channels API: Managed WebSockets for live notifications and instant updates.
  -Browser Web APIs:
  -Intl.NumberFormat: Multi-currency formatter supporting authentic locales(USD, INR, EUR, GBP, CAD, AUD, CNY, JPY, NZD, KRW).
  -Web Storage API (localStorage): Client-side persistence for auth tokens, theme preferences, and currency settings.
  -WebRTC/MediaStreams: Real-time consultation, audio/video counseling session context.
  -Canvas/WebGL Context: Rendering interactive fluid motion simulations.
  -Tools, DevOps & Infrastructure
  -Neon: Serverless cloud PostgreSQL database provider.
  -Vercel & @vercel/analytics: Cloud hosting and edge deployment with custom SPA routing rewrites (vercel.json) and real-time site performance analytics.
  -Docker & Docker Compose: Containerization for reproducible local environments and database instances.
  -NPM Workspaces & Concurrently: Monorepo orchestration allowing concurrent execution of both frontend and backend development servers (npm run dev).
  -Git & GitHub: Version control, branch tracking, and deployment triggers.
  -Nodemon: Auto-reloading server process supervisor during development.
